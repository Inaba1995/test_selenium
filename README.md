# Test Selenium

Набор UI-автотестов на Selenium WebDriver.

## Цель проекта
Освоить Selenium WebDriver для автоматизации тестирования веб-приложений.

## Задачи
- Настроить Selenium WebDriver
- Написать тесты для веб-интерфейса
- Реализовать проверки элементов и состояний

## Результат
Набор автоматизированных тестов для веб-приложения.

## Стек технологий
- Java, Selenium WebDriver
- JUnit, Maven

## Запуск
```bash
mvn clean test
```
